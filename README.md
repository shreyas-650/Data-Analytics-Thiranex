# Sales & Revenue Analysis Dashboard

A Power BI dashboard created to analyze sales data and present key business insights.

## Dashboard Features

- Total Sales
- Total Boxes Shipped
- Total Orders
- Average Box Price
- Monthly Sales Trend
- Sales by Product
- Top Products by Sales
- Sales by Country

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
